# 题目1

某水果经销商到一山区水果基地采购猕猴桃和苹果。猕猴桃和苹果的采购价分别为10元/斤和4元/斤，销售价分别为25元/斤和12元/斤。已知该经销商在本次经营中获利40000元，每种水果采购都超过500斤且为整数。那么该经销商的最佳投入资金是？

## 解析

猕猴桃利润 = 25 − 10 = 15 元/斤；苹果利润 = 12 − 4 = 8 元/斤。

设采购猕猴桃 x 斤、苹果 y 斤，则：

- 利润：15x + 8y = 40000
- 投入资金：C = 10x + 4y

由利润式解出 y = (40000 − 15x) / 8 = 5000 − (15/8)x，代入投入：

C = 10x + 4y = 10x + 20000 − (15/2)x = 20000 + (5/2)x

C 随 x 增大而增大，故要投入最少，x 应取最小可行值。

约束：

- x > 500 且为整数。

- y > 500：由 y = 5000 − (15/8)x 得
  ```
  5000 − (15/8)x > 500
  5000 − 500 > (15/8)x
  4500 > (15/8)x
  两边同乘 8/15：x < 4500 × 8/15 = 2400
  ```

  即 x 的取值上限为 x < 2400。

- y 为整数：由利润式 15x + 8y = 40000 得 y = (40000 − 15x)/8。要使 y 是整数，分子 40000 − 15x 必须能被 8 整除。其中 40000 = 8×5000 本身是 8 的倍数，所以只需 15x 能被 8 整除。而 15 与 8 互质（gcd(15, 8) = 1），8 整除不了 15，故必须由 8 整除 x，即 x 是 8 的倍数。

x 取大于 500 的最小 8 的倍数：x = 504。

此时 y = 5000 − 15×504/8 = 5000 − 945 = 4055 > 500。

投入资金 C = 10×504 + 4×4055 = 5040 + 16220 = 21260 元。

**答案：最佳投入资金为 21260 元。**
