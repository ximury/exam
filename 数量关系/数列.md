
# 题目1

红星中学高二年级在本次期末考试中竞争激烈，年级前七名的三科（语文、数学、英语）平均成绩构成公差为1的等差数列，第七、八、九名的平均成绩既构成等差数列，又构成等比数列，张龙位列第十，与第九名相差1分，张龙的英语成绩为121分，但老师误登记为112分。那么，张龙的名次本该是？

## 解析

三个数同时构成等差数列与等比数列，必有这三个数相等（由 2b = a + c 与 b² = ac 联立可得 a = b = c）。

设第七、八、九名的平均成绩均为 x。

- 前七名平均成绩构成公差为 1 的等差数列，名次每降一名分数少 1，故：

  第 1 名 = x + 6，第 2 名 = x + 5，…… 第 6 名 = x + 1，第 7 名 = x。

- 张龙位列第十，与第九名相差 1 分；第九名 = x，所以张龙（第十名）登记的平均成绩 = x − 1。

- 张龙英语实为 121 分，却误登为 112 分，少登 9 分；三科平均因此少算了 9 ÷ 3 = 3 分。

- 张龙真实的平均成绩 = (x − 1) + 3 = x + 2。

而 x + 2 恰好等于第 5 名（x + 2）的成绩，故张龙应并列第 5 名。

**答案：并列第五名。**
